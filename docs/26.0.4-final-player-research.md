## 已实现：命名播放书签

入口为播放详情页 **更多 → 播放书签**，对本地歌曲显示。

1. 保存当前秒数，或保存已设置的 A-B 区间；名称可选，留空时使用时间。点击位置书签直接跳转；点击片段恢复 A-B 循环，保持当前播放/暂停状态。
2. 每个书签支持重命名与删除；跨次启动保留，同一首歌可保存多个练习片段。此功能独立于自动恢复上次会话；不会让每首歌自动从旧进度开始。
3. 书签面板绑定打开时的歌曲。切歌、加载或切换输出时禁止跳转/新建，避免把旧歌曲的时间应用于另一首歌；仍可整理原曲已有书签。文件时长缩短后，超出时长的书签不执行 seek。
4. 存储为当前应用数据目录中的 `playback_bookmarks.json` 与 `.bak`。路径按 Windows 大小写与分隔符规范化；不向音乐文件写标签。按需异步读取，串行写临时文件并替换，保存成功才更新内存；写失败保留原数据且之后可重试。整体 JSON 损坏可回退备份；备份恢复时单首歌的路径缺失不影响其余书签。
5. 每曲最多 100 项，总计最多 5,000 项，文件上限 2 MiB；不会为腾位置静默删除旧书签。列表按需构建，面板随窄窗口滚动，按钮自动换行，使用现有 Material 主题。

音乐文件在资源管理器内改名或移动后，书签不会猜测新文件；保持路径相同或使用应用完整备份的路径映射时可以重新关联。在线流没有统一可 seek 能力，本轮入口限定本地音乐。
