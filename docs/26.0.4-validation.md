# 26.0.4 本机验收说明

2026-09-05，26.0.4 正式版检查记录。此前的未签名包是用户验收阶段产物；本次在完成发布前任务后统一构建、签名和装配正式版。

检查聚焦改动：开屏/搜索交互、详情播放控制、QQ搜索与评论解析、自定义源能力、队列编辑与保存、A-B循环、Windows任务与卸载交接，以及最后增加的多选、M3U8、书签和网易增强 API。共享翻译改变后，主程序和桌面歌词都重新构建。装配、签名及合成音频实机结果保存在本机工作区根目录 `DEVELOPMENT.md` 与 `.migration/logs/`，区分本机实测、历史检查和持续集成结果。

## 发布前追加验证

- 多选/选择生命周期 11 项测试通过，覆盖按显示顺序批量操作、刷新后选择保留、隐藏选择提示及窄窗口菜单。
- 网易增强 API 及相关设置共 37 项测试通过；真实部署固定上游提交，按固定录音验证搜索、详情、封面解码、歌词、两类评论两页和音频前缀。详情见 [独立 API 报告](26.0.4-api-release-additions.md)。
- 播放书签 6 项数据/交互测试通过，另检查明暗主题真实字体渲染、360×520 窗口和 1.8 倍字号。
- 歌单与迷你歌词的一组相关测试 121 项通过；随后 M3U8 边界修复的 5 项路径测试和最终 8 项文件/交互测试通过。包括重复项、跨盘/UNC、编码后控制字符、HLS 整体拒绝、导入确认、错误选择器、不支持的导出项目与目标文件保护。
- 主程序 `lib test` 和桌面歌词 `lib` 整合分析通过：无 error/warning，分别保留 18、16 条既有命名/弃用 info。不同测试组存在重叠，不累加冒充独立总数。
- 两个 Windows x64 Release 最终构建通过；AOT 内所需 Material 图标、字体与品牌资源核对无缺失。最终签名便携包/安装器使用同一批构建输出，并核对文件清单、哈希、版本与证书指纹。
- 新原生 Windows shell 策略测试纳入 Windows CI，与本轮既有本机 33 项策略断言及隔离冷/热启动实测相对应。

## 本轮重点

- 两个品牌展示各减少 0.5 秒，总时长约 2 秒，保留淡入淡出与辅助功能。
- QQ 评论支持不透明评论 ID；QQ 搜索使用本轮验证有效的公开搜索接口。
- 内置来源按已知评论能力显示分类；自定义来源先使用默认评论列表，再根据声明开放排序。
- 搜索按钮、清空、等待提示和过期请求取消；分类栏采用带图标的主题色圆角分段样式。
- 歌词详情播放控制透明描边；进度条使用圆角竖条手柄、交互形变和时间预览。隐藏页面停止监听进度；播放时间更新合并订阅，减弱动画时直接响应。
- 队列按条目整理、保存为歌单；本地歌曲 A-B 片段循环。
- Windows 任务与单实例指令转发；设置内打开卸载向导，先完成退出交接，保留音乐和用户数据。
- 修复冷启动“下一首”被尚未完成的源打开过程吞掉：恢复调用共享真实完成 Future，失败也释放任务队列，不增加轮询。
- 多选菜单补齐真实批量动作并在曲库通知后保留状态；M3U8 解析/编码在 isolate 执行，有体积与数量上限，不递归访问文件或网络。
- 命名播放书签按需加载并串行原子保存；切歌后禁止把旧曲目的位置应用到新曲目。修复详情页音量通知器未释放。
- 迷你歌词使用先淡出后淡入，避免新旧两段文字重叠；补充纯音乐标记识别。

## 检查边界

- 公开音乐接口的搜索、歌词、评论和播放/下载权限不同；具体曲目受版权、地区、账号与服务状态影响。成功搜索或取得封面不表示完整歌曲可以播放或下载。
- 对“卡农、稻香、Good Time”的逐来源、逐能力结果见 `26.0.4-api-compatibility.md` 和 `26.0.4-api-release-additions.md`。自托管服务未配置时不宣称已联网可用；试听与未命中原唱明确记录，不用翻唱替代原唱成功结果。
- 正式发行使用新 `CN=RCEIT.Inc` 十年自签名证书，指纹 `492AD4FCB49C9898B6B98251D4FE9FE78BDB56C1`。签名者及内容完整性与系统公信力分开验证；未申请公共 CA 证书，也未改变系统信任库。旧证书版本需手动下载安装器升级。
- 自动化/实机检查使用独立测试目录与合成音频，不改用户音乐，不执行真实卸载。QA实例不注册系统 Jump List；正式正常启动会注册。
- 不承诺覆盖所有显示器、声卡、触控设备或互联网上所有 API 的所有曲目。
