# 26.0.4 snapshot1

- 新增极简安装器，可选择安装位置和快捷方式，支持覆盖升级。
- 播放条支持直接拖动进度，增加上一首、下一首和播放队列。
- 主题可跟随系统或记住手动明暗选择，并实时响应系统变化。
- 分类增加码率和时长区间，收紧顶部布局，不再显示作曲家分类。
- 通用歌曲列表可确认后删除本地歌曲，并同步曲库、队列和歌单引用。
- 曲库支持增量刷新，优化搜索索引、时长校正、标签兼容、桌面集成与更新确认。

Windows x64 预览版；安装器与便携 ZIP 二选一。26.0.3 仍为稳定版，历史版本保留。

自有程序已使用 RCEIT.Inc 自签名证书签名，Windows 仍可能提示未知发布者。不受系统信任时，请手动运行下载的安装器。
