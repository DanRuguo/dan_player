# 26.0.4 snapshot1

- 新增极简安装器，可选择安装位置和快捷方式，支持覆盖升级。
- 播放条增加上一首、下一首和播放队列，支持拖动进度。
- 主题模式增加“跟随系统”，记住手动选择并实时响应系统明暗变化。
- 优化歌单详情工具栏、托盘字体与图标，改善桌面歌曲预览清晰度。
- 曲库支持增量刷新，改善歌曲信息编辑兼容性及失败提示。
- 更新前询问是否下载，新增预览版开关和安装器升级流程。

Windows x64 预览版；安装器与便携 ZIP 二选一。26.0.3 仍为稳定版，历史版本保留。

自有程序已使用 RCEIT.Inc 自签名证书签名，Windows 仍可能提示未知发布者。不受系统信任时，请手动运行下载的安装器。
