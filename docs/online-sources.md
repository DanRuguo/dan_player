# 联网歌源开关

“设置 → 联网歌源”分别控制 QQ 音乐、网易云音乐是否参与新搜索，默认均开启。卡片只展示能力与开关，打开设置或切换开关不会自动请求网络。

- 搜索开始时读取一次启用来源快照；已开始的搜索不会因随后切换设置被取消或改写。下一次提交搜索才使用新设置。
- 两源开启时仍并行搜索，结果按原有 QQ、网易顺序合并。只开启一源时不调用另一源，也不会把被关闭的来源记作搜索失败。
- 全部关闭后，非空搜索会直接提示“未启用联网歌源，请在设置开启”，不创建 HTTP 客户端。空关键词仍返回原有空结果。
- 关闭来源不删除已收藏的联网歌曲、歌单或队列，也不关闭现有歌曲的播放、歌词或封面解析。设置不改变主源和播放策略。

## 实际能力与限制

播放、歌词与封面只使用平台公开接口提供的内容，是否可用由平台决定。两源当前均不开放下载入口：匿名接口没有提供可靠的下载权限。开关不表示登录、付费、下载或绕过 DRM 的授权。

公开评论为只读功能，必须有有效的平台歌曲 ID，接口可用性仍由平台决定；开关不自动拉取评论，也不为本地歌曲猜测关联。没有加入 JS 歌源插件、新平台或私有凭据。

### 26.0.3 联网读取兼容修复

- QQ 搜索不再使用依赖库中已经频繁返回业务码 `2001` 的旧请求参数。应用使用匿名、无 Cookie 的当前签名搜索请求读取 `req.data.body.item_song`；歌词优先读取当前公开 LRC JSON（兼容 JSONP 和数字实体），旧 QRC 仅作高精度备选。服务码 `2001`、超时、429 与 5xx 仍只做一次有限重试；格式错误不重试。
- 网易歌词不再经过依赖库的旧 LinuxAPI 包装层，改为直接读取平台公开的 `/api/song/lyric` JSON，并同时识别 `lrc.lyric` 与 `tlyric.lyric`。`nolyric`、`uncollected`、空歌词和非对象响应不会被伪装成可用歌词。
- 当平台候选匹配但平台没有收录歌词时，内置候选会继续尝试 LRCLIB 的只读 `/api/search` 与 `/api/get/{id}`。同步歌词按真实 LRC 时间轴显示；只有 `plainLyrics` 时保留为一个明确的“无时间轴歌词”文本块，详情页可完整阅读，紧凑播放器只显示首行摘要，不生成伪时间戳。LRCLIB ID 可单独持久化，但不会被当作 QQ/网易的评论身份。
- 歌词自动匹配、手动候选和歌曲信息查询共用标题规范化。只在查询/评分时移除末尾的 `-OP-`、`-ED-`、`short ver.` 等版本说明，不修改本地标签；候选仍跨来源汇总后按标题、艺术家、专辑相关度降序排列。
- 自定义歌词接口返回可读歌词但没有平台歌曲 ID 时，自动歌词可以使用该结果；“指定默认歌词”的内置 QQ、酷狗、网易候选仍会单独搜索并展示，便于选择可持久化的平台来源。

2026-08-29 使用固定公共词进行过一次有限匿名探测：网易查询“`結想は花となる -OP- short ver.`”返回精确歌曲 ID `3427740763`，但歌词接口明确返回 `code=200`、`uncollected=true` 和空 `lrc`，这属于平台未收录而非解析失败。LRCLIB 以规范标题和歌手查询返回精确记录 ID `38005804`，提供非空 `plainLyrics`、`syncedLyrics=null`；QQ 旧请求返回 `req.code=2001`，当前签名请求查询“卡农”返回 `code=0`、`req.code=0`、`item_song`。所有探测均未登录、未带 Cookie、未请求音频，并遵守 429/超时的有限重试；结果不作为平台长期可用性的保证。

## 持久化与测试边界

设置键为 `OnlineSources`，值是已启用来源 ID 的数组：`["qq", "netease"]`、`["qq"]`、`["netease"]` 或 `[]`。缺失或非数组值沿用双源默认；显式空数组保留全关。数组中的未知 ID 被忽略，不会触发未知来源；仅含未知 ID 的数组等价于全关。

此面板使用严格保存模式：磁盘保存失败会显示错误，并保留当前会话的选择；下次启动仍以最近成功保存的配置为准。旧的其他设置调用仍保留默认不抛出异常的兼容行为。

`OnlineSearchResponse` 保持原接口。新增测试用必填的双源 hook 注入控制响应，另从真实服务入口断言全关时零 HTTP 客户端；设置测试使用工作区隔离文件与窗口方法替身，不读取真实用户设置、不启动音频。覆盖并发快照、部分失败、去重、四种配置保存/读取、触控/键盘、窄窗和 200% 字号，以及迟到保存和销毁边界。严格保存专项使用临时目录占据 `settings.json` 文件路径，验证真实默认保存链的错误传播、界面提示和后续重试，而非仅注入失败回调。平台实时可用性不属于这些离线回归的证明范围。
