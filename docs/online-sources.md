# 联网与歌词

来源按管理方式分为两组；分组不代表可靠性排名，也不代表接口获得平台开放授权。

- **平台直连与公开 API**：QQ 音乐、网易云音乐和 LRCLIB。固定名称、能力与地址，只提供启用／停用。
- **第三方 API**：内置酷狗适配、LRC API，以及用户添加的服务。可修改名称、地址、协议、能力和公开请求头，可分别启停、测试、删除、导入或导出。

打开设置或切换开关不会自动探测网络。歌曲搜索只取候选；播放和下载地址在用户选择后才解析，不会批量预取整首音频。

## 实际能力

QQ 与网易提供歌曲搜索、音源解析、歌词、封面和只读评论。下载入口按实际解析结果开放尝试，不再以“官方”“非官方”标签或缺少额外许可字段一概关闭。单曲需要登录、接口拒绝访问、没有可用地址或只有试听片段时，不会伪装为完整可下载歌曲。

酷狗适配参考 ZeroBit 的搜索／歌词／封面使用方式与 ECHO 的音源解析流程，独立实现对应协议。所有端点可编辑，歌曲的可用性仍以当次响应为准；没有证据表明当前协议提供评论，因此不预设评论能力。LRCLIB 是公开歌词目录，不作为整曲音源。LRC API 作为普通内置第三方项显示，不再使用“旧版”名称。

第三方配置支持 Dan Player 通用 v1、LRC API 歌词协议、酷狗协议和用户自托管的 go-music-api 兼容协议。通用 v1 中，标题、艺术家、专辑与时长是基本搜索字段，其他歌曲信息和封面按声明能力接收。具体字段与示例见 [API 接入说明](custom-music-source-api.md)。

配置声明下载能力后即可尝试下载；缺少 downloadAllowed 表示尚未确认，而非禁止。明确的 downloadAllowed: false、canDownload: false、登录要求及访问拒绝仍会阻止下载。播放器不代替用户取得登录、付费或 DRM 权限，不执行远程脚本，也不捆绑平台账户或登录凭据。

## 按歌曲测试 API

点击第三方来源的“测试”，输入歌曲名称（必填）、艺术家和专辑（选填）。可以使用“卡农”等常见曲目，但不同演奏版本、纯音乐无歌词、平台未收录等都可能导致部分项目没有样本。

测试分开显示搜索、歌曲信息、封面、歌词、评论、播放、下载的结果，并区分成功、无样本、不支持、超时、需要登录和请求失败。播放／下载仅解析地址及读取少量数据，不启动播放、不保存完整歌曲。每请求和整轮均有时限、响应大小与并发上限，关闭弹窗或取消会终止请求。

一次没有匹配结果不等于 API 永久不支持。测试不自动改能力；用户确认后才将检测成功的能力应用到配置。测试可用于停用的来源，但不会自动将它重新启用。

## 设置与已有歌曲

- QQ／网易开关控制下一次搜索，已有收藏、歌单、队列与歌曲身份不会被清除。
- 第三方来源停用、删除或编辑后，新的搜索、歌词、封面、评论、播放与下载请求都按当前配置验证。迟到响应与旧音源缓存不能绕过配置变化；正在下载时配置失效会停止并清理未完成文件。
- 酷狗歌词与歌曲使用同一预设配置，不再保留绕过开关、名称和 URL 修改的隐藏歌词入口。
- 无可用搜索来源时立即提示，空关键词不发送请求。多来源查询限制并发与等待时间，单个来源失败不清空其他来源的成功结果。
- 收藏、歌单与评论关联保存稳定的配置 ID；重新导入同一 ID 可恢复关联。更换不兼容的协议时，旧歌曲 ID 可能无法继续解析。
- 缺失自定义封面回退到歌曲封面或默认图，不影响歌单内容。

初次安装带 LRC API 与酷狗预设。已有 LyricApiUrl 保留用户地址与开关，原默认名称改为 LRC API；已有新格式配置优先，不被旧键覆盖。预设仅作一次性迁移，明确清空或删除后的来源不会在重启时复活。删除的预设可手动重新添加。

最多保存 32 个第三方配置。导入会跳过无效项，ID 冲突时由用户选择更新、仅新增或取消。保存失败会明确提示，不会伪装为已保存。导出包括地址和公开请求头，请勿把秘密写入其中；凭据仅允许引用，安全凭据存储未接入前不会发送认证请求。完整缓存备份还包含设置、收藏、歌单和评论关联，但不复制音乐文件。

## 参考与验证边界

协议及交互参考 [ZeroBit Player](https://github.com/Empty-57/ZeroBit-Player/tree/e47d34fb5c946a6cf10041377b15eb6f089f5d28)（GPL-3.0）和 [ECHO](https://github.com/Moekotori/ECHO/tree/45ea979d18da08234307b13c215f56abe3c00556)（LGPL-3.0-only）；[go-music-api](https://github.com/guohuiyuan/go-music-api/tree/bacdfbe6cf6a5ba7331463d2039e3aac915c627f)（AGPL-3.0）仅为用户自托管兼容目标。Dan Player 没有复制或捆绑这些项目的实现代码或服务器。

离线回归使用本机临时 HTTP 服务、隔离设置与界面测试，覆盖超时、取消、限量读取、配置变更、下载清理、迁移和窄窗／大字号。实时探测只说明当次接口及曲目结果，不保证所有歌曲、地区和未来时间都可用。
