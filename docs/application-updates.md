# 应用更新

播放器使用 GitHub Release 的完整安装器更新，不在运行中替换 DLL，也不使用自行拼装的差分补丁。

## 下载与安装

1. 检查更新只读取版本信息，不自动下载。发现新版本后先展示版本、更新内容和下载确认；预览版有单独的风险提示。
2. 用户确认后下载匹配版本及架构的安装器，并验证 SHA256。可以取消下载；失败可重试。若某个历史发行未提供校验文件，仅提供手动安装入口，不允许“重启并更新”。
3. 下载完成后，用户另行选择“重启并更新”。程序再次核验文件哈希、Windows 签名信任、与当前播放器一致的签名证书及安装器产品版本。
4. 安装器确认接管后，播放器才正常退出。安装器等待原进程退出，升级当前实际运行目录，保留用户数据和原快捷方式选择；成功后重新打开播放器。

启动失败、签名不受信任或接管超时不会强制关闭播放器。界面保留打开下载位置、手动运行安装器的入口。安装器不会强杀仍在运行的播放器；不能安全写入时停止升级或提示重试，已有文件由安装事务备份和回滚。

本次 RCEIT.Inc 证书是自签名证书，不等同于公共 CA 代码签名。多数设备不会默认信任它，因此可能只能手动安装。播放器和安装器均不添加受信任根、不绕过 Windows 签名验证。

## 预览版开关

设置中的“接收预览版更新”决定是否检查 snapshot 等预览版本。稳定版首次默认关闭；主动使用预览版本且尚未设置此偏好时默认开启。用户明确选择后会记住，不再由版本类型覆盖。

开启这个开关只是允许检查预览版，不是自动下载或安装授权；每次下载仍需确认。关闭后只查找更高版本的稳定版，不会自动降级。手动“检查更新”和自动检查遵循同一通道选择。

26.0.3 的旧检查器只接收稳定 Release，无法发现本次 snapshot。首次尝试预览版请从 GitHub 的预览 Release 手动下载。
