# 当前分类与文件夹统计

左侧“艺术家”入口统一为“分类”。这是总乐库的浏览视图，不搬动音频文件、不修改音乐标签，也不另建或重排歌单。

## 七种分类

| 分类 | 依据与缺省处理 |
| --- | --- |
| 艺术家 | 原艺术家标签，遵循设置中的分隔符；空值归入未知艺术家。 |
| 专辑 | 专辑名和专辑艺术家共同区分；没有专辑艺术家时按该曲艺术家区分，避免不同艺人的同名专辑混在一起。 |
| 码率 | 使用音频索引中的标称码率，分为 128 kbps 及以下、129–192、193–256、257–320 及高于 320 kbps；缺失或无效值归入未知码率。 |
| 时长 | 按歌曲总时长分为少于 2 分钟、2–4、5–9、10–29 及 30 分钟以上；缺失或无效值归入未知时长。 |
| 语言 | 分类页与统计页共用判定，归为中文、英文、日文、韩文、其他语言或未识别；优先语言标签，再看本地歌词原文线索，最后按歌名、作曲或参与创作艺术家、专辑等元数据作有来源标记的文字推断。 |
| 文件格式 | 本地文件扩展名，不冒充解码检测；联网歌曲和无有效扩展名的文件归入未知格式。 |
| 来源 | 本地或联网。分类详情保留各歌曲本身的播放能力与菜单差异。 |

可在分类内搜索、进入分组播放或加入歌单。七种分类选项直接展示在顶部同一行，窄窗与大字号时可横向滚动，不再藏入下拉菜单。旧艺术家/专辑路由及已保存的启动页索引继续可用；旧作曲家深链仅保留兼容，不再出现在分类选择器。

## 证据边界与只读读取

- 语言标签优先于文字推断。元数据中日文假名、韩文及明确其他文字体系优先。主标题为纯汉字且没有这些优先线索时，艺术家拉丁艺名或专辑附带 `OST` 等不否决中文文字推断；主标题自身汉字/拉丁混合仍保留未识别。可用独立字段均为拉丁文字时作英文推断，单独的英文歌名不足以确认语言。“其他”需要对应语言标签、其他文字体系或明确的跨语言线索，不能作为混合元数据的默认桶。
- 标题为空、未知或来自完整文件名时，仅为分类去掉真实文件扩展名，避免 `.mp3` 被当作拉丁语言线索。原来的 `Audio.title` 和磁盘文件名均不改动；联网地址不参与此回退。
- 优先读取同目录同名 `.lrc`，否则通过已有只读原生接口读取内嵌歌词。LRC 按常见约定只保留同时间戳首行，忽略后续翻译/音译行、`//` 后译文、元数据行与创作人员署名；多个时间戳的原文同样去重。文件若采用“译文在前”的非标准顺序，该约定无法保证原文识别，因此所有歌词判断仍标为“歌词”，不声称实际识别了音频演唱语言。
- 语言分类与统计均公开区分“标签 / 歌词 / 推断 / 未知”。作曲信息参与语言判断时只属于元数据推断，绝不升级为语言标签；证据不足保持未识别。
- 异步扫描最多每批 8 首；统计与分类共享进程内只读歌词 LRU 缓存（最多 1024 项、4 MiB 文本）。每次命中先核对音频和同名歌词的大小及修改时间；相同源的并发读取复用请求，异常不缓存，空结果最多缓存 30 秒。它不写音乐、歌词、用户设置、曲库索引或磁盘缓存。
- 分类快照冻结元数据，艺术家等字段变化会使旧结果失效；切换分类复用当前快照，乐库刷新重读。默认查询不会下载歌词，也不会读取联网曲目的流地址。

## 旧索引与标签

索引版本继续为 113，不因新增分类而强制重建整库。旧记录缺少码率或时长时可安全归入未知；`composer`、`album_artist` 及 `classification_version` 等旧字段继续用于兼容、详情与语言线索。

刷新乐库时，对文件未变化的旧记录只补充缺失字段；原标题、路径、时间和其他字段保留。读取失败不把旧记录替换为空标签，后续刷新可重试。这个过程不写入音频文件；播放队列与歌单引用也不因浏览分类而改变。

## 本地文件夹占比

统计页的曲库概览新增“本地文件夹”。文件夹分布可切换歌曲数量与占用空间，按曲库登记的完整直接父目录分组；不同盘符的同名文件夹分开，不递归合并子目录。

- 数量统计本地曲目，包含缺失或暂时不可读的记录；重复路径和已识别为同一物理路径的别名按扫描器规则去重。
- 空间只计本次只读检查成功取得的文件字节数，排除联网歌曲、缓存、缺失和不可读文件，不按码率估算。
- 当前指标显示前 7 个文件夹，其余合为“其他文件夹”；空间总量为零时全部为 0.0%，不制造占比。
- 切换数量/空间只重算内存结果，不重新扫描。外部文件变化后可手动刷新。
- 语言、格式、文件夹三张分布卡在同排时等高，环图使用相同尺寸；窄窗纵向排列并随内容增高，不裁切图例。

分类和统计使用同一分类函数和本地歌词读取规则。同一曲目集合与同一源文件状态下，语言结果保持一致；统计仍独立执行文件大小核实和重复物理路径去重。

## 只读审计

`scripts/audit_classification_metadata.py` 可对指定目录检查 ID3、Vorbis 和 APE 标签，默认仅打印汇总，不输出路径列表或大段歌词，也不写入源目录。机器探针使用其显式 `--descriptors` 模式，经子进程内存消费描述符（含路径及标签，不含歌词），不会生成磁盘清单。用户授权目录的只读验证已完成；公开文档不保留私人曲库规模、分布、曲目或路径。真实数据中的个别计数不进入应用分类逻辑；应用已有的 Windows/索引艺术家回退可能提供额外信息。

实际应用分类器与已有 Release 原生歌词读取的端到端核对方法见 [只读验证摘要](classification-readonly-qa.md)。它严格核对分类与统计的语言及证据计数。公开展示使用独立的虚构数据；展示图不作为真实目录验证的替代证据。
