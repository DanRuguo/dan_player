# 26.0.3 桌面与播放体验

本轮是现有 Dan Player 的增量更新，版本仍为 **26.0.3**。不替换曲库、歌单、收藏或播放历史的数据模型，也不导入其他播放器的用户配置。

## 功能入口

- **设置 → 曲库与播放**：0.5、0.75、1、1.25、1.5、1.75、2 倍保音高播放；WASAPI 独占输出。歌词详情页原先很小的 `Shrd/Excl` 控件改为当前倍速按钮，输出模式集中放在设置中。
- **设置 → 联网与歌词**：弹性歌词跟随、桌面歌词竖排；原有歌源、歌词接口和默认歌词源保留。
- **设置 → 外观与背景**：主界面、歌词详情、迷你播放器独立选择纯色、Windows 窗后毛玻璃、专辑封面或自定义图片；按来源调节模糊、透明度，并可启用图片缓慢漂移。
- **设置 → 桌面与快捷键**：关闭窗口后在托盘继续播放、任务栏缩略图播放按钮、任务栏歌曲预览、快捷键说明。两个任务栏开关独立，默认开启。关闭到托盘默认关闭，以免改变旧版本的退出习惯；启用后标题栏关闭、Alt+F4 和迷你窗口关闭走同一逻辑。
- **设置 → 更新与关于**：保留原有更新和问题反馈入口。分组初次访问时加载，访问过的分组保留输入和滚动位置；窄窗口使用分类下拉框。

## 后台与系统托盘

托盘菜单提供显示窗口、迷你模式、上一首、播放/暂停、下一首、桌面歌词和退出。播放按钮复用当前会话，不启动第二个播放器。双击托盘图标可恢复窗口，菜单的“退出”始终真正退出。

Windows 任务栏缩略图提供上一首、播放/暂停、下一首三个控制按钮，并可显示封面、歌曲名、艺术家和专辑的小卡片。预览使用当前主题和字体；播放按钮跟随封面主题强调色，同时按系统任务栏明暗背景调整可读性，高对比度模式尊重系统色。关闭歌曲预览、没有当前歌曲或原生接口不可用时恢复系统窗口预览。DWM 的 Peek 预览也可能使用同一张受限小卡片。

卡片仅在歌曲、封面、主题或字体改变时重绘；不截取桌面、不逐帧抓取播放器、不把图片路径交给 Shell。单次卡片为 480×240 RGBA，原生严格限制每轴 512 像素和总量 1 MiB，并按系统请求等比缩小。图片加载与播放控制独立，连续切歌丢弃旧结果，关闭后不会发布迟到卡片。

**没有常驻任务栏歌词**，也没有把歌词嵌入 Explorer 的隐藏开关。用户要求的“缩略图控件”与常驻任务栏文字是两项不同能力；当前 ZeroBit 固定快照及 Win10/Win11 可行性边界见发行包 `TASKBAR-LYRICS.md`。

隐藏前重新确认托盘图标可用；失败时正常退出，防止播放器变成找不到的后台窗口。Explorer 重启后重新注册图标和按钮。原生部分只接入 Shell 控制，不改动之前的 Win10/Win11 非客户区、拖动和毛玻璃计算。

退出只清理已经创建的资源，不因只打开歌词或设置而初始化 BASS。歌词的迟到解析、窗口启动和 IPC 结果在退出后失效；清理某个服务失败时仍尝试清理其余服务。桌面歌词收到主程序管道 EOF 时自行关闭，防止残留孤立窗口。

## 自定义与动态背景

导入 PNG/JPEG/WebP/BMP 静态图片时先校验，生成专门用于背景的受控副本，原图保持不变。设置只保存托管图片标识，不依赖原图片一直位于原路径。单图输入上限 20 MiB，背景副本控制为最长边 2048、最多约 4 百万像素；托管目录上限 24 张 / 96 MiB。错误、取消和较早完成的过期导入不会覆盖较新的选择。

背景副本的缩放只影响背景层，不降低歌曲封面、歌单封面或分类图的清晰度。清理只针对没有被当前会话、已保存设置或备份引用的托管副本；读取保存引用失败时不执行删除。

动态效果是缓存图片的低频平移/缩放，**不是视频、FFT 驱动或网格渐变**。最多 20 次/秒，只有背景纹理更新；专辑和自定义图片可用，原生窗后毛玻璃不使用该效果。暂停、窗口隐藏/最小化、页面离开、系统减少动画或高对比度时停止。Windows 原生毛玻璃继续由系统提供，不截屏桌面，不随专辑图更换。

## 歌词与倍速

弹性跟随只在正常逐句前进时使用有阻尼的缓动，过冲限制在 8 像素内；手动跳转和系统减少动画时不回弹。保留手动滚动后的暂缓跟随、当前行强调、逐词时间和译文，不重新排版整段文本来制造动画。

桌面竖排不是把整行旋转 90 度。CJK、Hangul、kana 与 emoji 按完整 Unicode 字素簇从上到下直立排版，CJK 标点保持独立；以空格分隔的外文单词（包括撇号词、连字符词、缩写和数字）则作为一个直立横排单元。原文和译文分列，200px 窄列配合 200% 文字缩放时，过长的双语单词会在各自列内缩小适配而不溢出。具备真实逐词时间时，外文单词在本格内水平高亮，CJK 内容仍自上而下高亮。横排、竖排在本次运行中分别记忆窗口大小和位置，并限制到当前显示器工作区；方向偏好会保存，方向切换失败时恢复原窗口模式。锁定、穿透、移动、调色和关闭入口保留。

桌面歌词的调色板按钮打开“歌词外观”：新增 **文字不透明度（20%–100%，默认100%）** 和 **文字描边（默认关闭）**。默认保留原软阴影；描边启用后使用缓存的真实字形轮廓，不改变竖排单词、逐字遮罩或播放时钟。文字透明度只影响原文和译文，操作按钮仍清晰可用。歌词与新控件默认跟随播放器的动态封面主题；只有显式选定固定文字颜色时歌词才停止跟随，描边随当前文字颜色重新选择黑/白对比色。面板在窄窗口中限制宽高并滚动，保留背景透明度和全部色板操作。

主程序在独立 `DesktopLyricAppearance` 设置字段中保存原文/译文字号、固定文字颜色或跟随主题、背景不透明度和上述两个新选项；旧设置缺少字段时保持旧默认，非法数值逐字段安全回退。歌词组件仅通过 stdin/stdout 发送变更，不自行写用户文件。连续滑动停止500毫秒后合并保存，关闭歌词窗口时提前提交最后一次变更；主程序退出等待已提交的保存任务，仍受全局2秒退出保护限制。保存失败保留当前会话效果，并在主窗口及仍打开的歌词外观面板显示反馈，面板提供重试保存；异常终止或磁盘长期无响应时不能保证落盘。旧进程消息和迟到回执不会回滚新选择。

播放速度由独立的 BASS_FX Tempo 流实现，未用提高采样率的方法代替保音高。歌曲时长、跳转坐标和 LRC 时间仍是源媒体时间，主歌词和迷你歌词继续使用真实进度；桌面歌词 IPC 额外携带倍率，旧消息缺少倍率时按 1× 处理。切速不重新加载歌曲，可能有短暂算法缓冲过渡，随后收敛到新速度。

听歌总时长、每日和每小时分布按实际经过时间累计；完成/提前跳过判断按实际消耗的媒体时长计算，因此不会把慢速听了半首误算成整首。调整速度不会增加一次播放记录。

## 独占与兼容性

输出切换保留原有暂停/播放状态、位置和倍率。新输出打开或初始化失败时尝试恢复原输出，不无限重试，也不抢占已被其他程序占用的设备。格式不兼容时仅尝试一次 WASAPI 自动格式协商；独占不意味着必然无重采样。

正在验证的临时输出模式与下一首使用的已确认模式分开维护，因此失败回退尚在等待网络时切下一首，不会继承失败的输出模式。显式跳转会先清除独占设备的旧缓冲，再按原播放状态恢复；暂停时跳转不会开始播放。普通暂停不丢弃已缓冲的尾段。相关 API 语义见 [BASS_WASAPI_Stop 官方说明](https://www.un4seen.com/doc/basswasapi/BASS_WASAPI_Stop.html)。

这仍是可选功能：设备驱动、硬件格式支持及其他应用占用会影响结果。尚未在两台独立的 Win10/Win11 实机上完成听音、热插拔、Explorer 重启及多显示器交互验收，不能把策略测试或编译通过等同于双系统实机验证。

实机验收建议：先保持共享输出，确认关闭到托盘后继续播放且能恢复；检查任务栏三个按钮。再分别测试三场景背景、最小化/恢复和原生窗后变化；桌面歌词切横竖排、暂停跳转及 0.5×/2× 同步。独占输出最后单独测试，关注设备占用提示、切换失败后的恢复与关闭退出，不把其他应用的设备占用视为播放器应当强制解除的状态。
