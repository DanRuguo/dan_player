# 26.0.3：统一界面与可选背景

版本号保持 **26.0.3**；本轮不修改已有乐库、歌单树、收藏或歌词文件。

## 界面

- 分类恢复圆形封面、下方名称及数量；图片、文字、键盘均可进入分类歌曲。
- 歌曲排序使用统一控件：当前字段、升降序、可滚动分组菜单；支持名称、艺术家、专辑、作曲家、音轨、时长、时间、文件信息及来源。相同值保留原序，缺失值在两个方向都排最后。排序只改变显示及顺序播放的遍历，不覆写自定义混排。
- 各歌曲网格统一为 48px 封面和最多两行歌名；不显示歌手/专辑/时长副信息，保留右侧菜单、长按、拖动与多选。普通文本使用约 64px 行高，辅助功能大字号自动增高。
- 歌词主句更大、更重，邻句降低透明度；620ms 滚动曲线快起慢停，seek 使用更短过渡。布局以最终字号预留空间，缩放只发生在绘制阶段。逐字高亮仍只使用真实时间戳。
- 音柱位于播放进度条正上方。FFT 数据直接通知绘制，不按每帧重建/布局组件；重复数据不重绘，后台、隐藏路由及减少动画时取消订阅。
- 页面进入保留内容分组浮现；返回增加 180ms 淡出。背景不平移，返回过程中阻止重复点击；减少动画模式不显示淡出。页面标识使用路由自身 key，草稿与下层页面状态保留。

## 背景设置

设置中的“背景与毛玻璃”分别配置主窗口、歌词播放页、迷你播放器：

- 不模糊：实色；保留上一次透明度和模糊参数。
- 窗后背景：Windows 实时窗后毛玻璃，可调整背景透明度；半径由 Windows 管理，不能把 Flutter 内部滤镜当成桌面模糊。
- 专辑封面：跟随当前歌曲，可调整背景透明度及模糊强度。仅处理背景，前景图片、文字和控件不变模糊。

原生策略保持 Win11 Desktop Acrylic → Win10/早期 Win11 Blur3 → 实色的探测顺序。未启用任何窗后背景时停用原生毛玻璃；普通移窗、切歌、调透明度、进出迷你不会反复重配。高对比度优先回退；所有设置只作用于本应用，不修改系统透明设置。

`Backgrounds` 为新增独立设置字段。缺失/非法值安全回退，未知未来来源不会崩溃；滑块只在松手时保存，过时的异步保存不允许覆盖更晚的设置。

## 歌源与评论

- 设置中可分别启用 QQ 音乐、网易云音乐；默认保留两个来源。开关只控制新的搜索，不移除总乐库、收藏、歌单或队列，也不中断已有歌曲。全部关闭会明确提示且不发请求。详见 [online-sources.md](online-sources.md)。
- 联网歌曲的播放页“更多”和歌曲详情提供“歌曲评论”。仅按可靠的平台歌曲 ID 读取，先加载热门，点击最新才发起对应请求；不按本地文件名猜测歌曲。
- 评论只读、不登录，不请求头像或媒体；显式分页，每类最多 10 页，重复页停止。取消、超时、平台拒绝、无评论与格式异常均有单独处理。不发布评论、不点赞、不提供无授权下载。
- 背景和迷你模式被动监听播放器就绪，既不为显示界面提前初始化音频，也不会因界面早于播放器挂载而永久停在占位状态。
