# 智能歌单

26.0.4 的歌单工具栏“更多 → 智能歌单”可以新建和管理规则。填写名称，再按需指定关键词、艺术家、专辑、文件格式和最短/最长秒数；所有已填条件同时满足才入选。结果可按名称、艺术家、专辑、加入时间或时长排序，仅查询本地扫描曲库。

编辑时显示预览，曲库刷新后重新计算；保存的是规则，打开后会包含新加入的匹配歌曲。预览只计算当前规则，分批让出界面执行时间，排序在独立 isolate 中完成；过期结果不会覆盖新条件。结果支持播放、多选、加入普通歌单和 M3U8 导出。加入普通歌单、导出或送入播放队列时使用当时的结果，不在后台改动正在播放的队列。

规则存于应用数据目录 `smart_playlists.json`，整体数据备份会包含此文件。最多 100 条规则，文件上限 512 KiB；写入串行执行并保留一份备份。读取或保存失败可以重试，保存失败会保留表单和旧规则；损坏文件不会被空列表覆盖。名称最多 120 字，时长范围为 0–86400 秒。

相关验证包括 6 项条件/排序/取消/存储测试和 7 项界面测试，覆盖保存失败、旧预览取消、结果转普通歌单、导出以及英文 320 像素宽、两倍字号。歌单工具栏另验证新入口和只读状态。
