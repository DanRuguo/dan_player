# 26.0.4 API 兼容性与本机实测

检查日期：2026-09-05。范围是播放器实际接入的内置服务、预设和自定义协议；不是对所有歌曲、所有地区或登录账户作可用性保证。本次按用户指定的“卡农、稻香、Good Time”检查，并额外复测截图中的“哈基米音乐”。

## 已修复的问题

1. **QQ 评论误报格式异常**：平台歌曲 ID 仍是数字，但评论 `CmId` / `commentid` 已返回 `1!…` 等不透明字符串。旧实现将评论 ID 也限定为纯数字，导致成功响应中的整页评论被丢弃。现分开校验歌曲与评论标识，保留评论去重、512 字符上限和控制字符检查。真实热门/最新响应分别为 118,661 / 60,692 字节，没有超过原 1 MiB 限制。格式错误与超过大小限制现在有不同提示。
2. **QQ 搜索 2001**：原移动 MusicU 搜索返回 2001，响应同时给出登录反馈页；补齐上游客户端参数仍如此。已改用可匿名访问的 HTTPS `c.y.qq.com/soso/fcgi-bin/client_search_cp`，解析完整歌曲列表的 `songid`、`songmid`、`albummid`、`media_mid/strMediaMid` 等字段。四个关键词均返回 10 条歌曲，评论、歌词、封面和音频继续使用所选歌曲的原平台标识。没有用搜索建议冒充完整结果，也没有对 2001 无限重试。
3. **自定义评论被硬套热门/最新**：通用请求先读取来源默认列表，不发送 `sort`。响应明确声明 `supportedSorts` 后，界面才提供相应分类；用户点击后才发送排序参数。QQ、网易适配器的热门/最新契约已单独确认。歌词/酷狗等不具备评论能力的源不再参与评论候选检索。
4. **网易元数据匹配缺封面**：搜索响应常不带专辑图片；旧匹配界面对内置候选直接返回，不利用歌曲详情。现在选中网易候选时，按确认的歌曲 ID 请求公开详情，补齐专辑封面；只接受相同 ID，保留原播放/下载标志。单次请求可取消，整体 12 秒、256 KiB 上限，不对整个搜索列表逐条发请求。图片继续经过现有 HTTPS 规范化、大小限制和解码流程，填入编辑器后由用户保存标签。
5. **酷狗长查询合法响应被大小门槛拒绝**：`Good Time Owl City Carly Rae Jepsen` 默认 25 条的真实响应为 141,452 字节，超过旧 128 KiB。只把酷狗搜索限额调整到 256 KiB，元数据/封面仍为 128 KiB；其他协议预算、25 条结果上限、超时、取消和声明/流式体积检查保留。正常默认查询现在直接成功，无须降低结果数或自动重复请求。

没有跨所有音乐平台通用的远端评论 URL/参数。应用层可以统一成“候选歌曲 → 确认来源及 ID → 评论列表”，再显示该来源实际支持的排序；不会按同名歌自动串接到另一个版本。仅歌词服务无法因此变成评论或下载服务。登录、评论发布、点赞、云歌单等账户写操作不属于当前匿名读取功能。
