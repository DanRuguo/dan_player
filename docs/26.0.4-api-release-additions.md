## 使用入口

1. 自行部署 [上游服务](https://github.com/NeteaseCloudMusicApiEnhanced/api-enhanced/tree/d55d92cd0031d7c7746b7068faecd7ade1d354ac)，确认地址可用。上游文档要求 Node.js 22 或更新版本。
2. 播放器“设置 → 第三方 API → 添加内置预设 → 网易云增强 API”。预设默认关闭，地址为 `http://127.0.0.1:3000/`。
3. 编辑为实际服务地址并启用；可用“测试”逐项验证。已有收藏、歌单和评论关联使用稳定的 `custom:netease-api` 身份，修改地址不会混到内置网易来源。

歌曲评论先读取标准列表，再显示适配器实际支持的热门/最新分类。最新评论使用 `comment/music`，热门评论使用同目录 `comment/hot`；分别读取 `more` 与 `hasMore`。本次两个排序均实测第 1、2 页，无重复条目。并未将 `comment/new` 的游标分页假装为页码。

所有请求复用原传输层的取消、6 秒总时限和拒绝重定向逻辑。搜索上限 25 条 / 256 KiB，详情及歌词 128 KiB，评论 256 KiB，音频解析 32 KiB。搜索不逐首追加详情/音频请求；用户选中后才查询。已知网易 CDN 旧 HTTP 图片地址升级为 HTTPS；其他自托管地址保留用户所选方案。

播放与下载权限分别检查。有效播放 URL 不意味着允许下载，只有 `song/download/url` 返回对应 ID 的有效完整音源才能下载。响应带 `freeTrialInfo` 时保留限制，不将试听片段展示成整首音频。播放器不发送账号 Cookie、不实现远程脚本加载、解锁或账户写入。

## 三个关键词的真实结果

本机临时部署上游 4.40.1，绑定 `127.0.0.1:33164`，使用匿名请求，`ENABLE_GENERAL_UNBLOCK=false`。通过新适配器搜索“卡农”“稻香”“稻香 周杰伦”“Good Time Owl City Carly Rae Jepsen”，每次取得 25 条结果。没有向真实音乐目录写文件，也未下载完整歌曲。音频检查最多读取 4096 字节响应并核对 HTTP 状态和媒体类型。
