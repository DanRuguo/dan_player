# 26.0.5-snapshot.1

本次交付 Windows x64 未签名完整便携包与安装器。便携包完整解压后运行 `Dan Player.exe`；也可使用安装器安装。两者使用同一批主程序、桌面歌词与运行库。

- 统一队列、歌词页、迷你播放器及列表操作图标的主题色，切换明暗或封面配色后同步更新；禁用、选中和有底色按钮保留各自的状态与对比度。
- 音乐、分类、文件夹和歌单使用随机／循环双段按钮；歌词详情页保留独立透明图标，两种外观共用全局状态，悬停显示当前模式。随机独立开关，循环依次为关闭、列表循环、单曲循环；按钮只切换模式，手动点歌才播放。修复随机模式下关闭循环仍自动开始下一轮的问题。
- 调整“下一首播放”封面飞行动画：保留原先的缓起步，接近队列时温和减速，按弧线实际距离控制速度，避免收尾突然加速。
- 常规动画采用 120／180／240／300 ms 分档，页面返回从 420 ms 缩短到 240 ms；歌词切换和滚动采用 480／600／720 ms 分组，保留音乐时间同步及减少动画设置。“下一首播放”继续使用单独的 520 ms 曲线。
- 修复异常 ID3 标签导致 MP3 内嵌封面漏读，以及 Windows 文件类型图标被误认作歌曲封面的问题；失效旧封面缓存，统一专辑分类卡片与详情的首曲选择。
- 重做 Windows 任务栏缩略图和大预览：分别适配大小画布，增加主题渐变、封面与信息层次、播放状态和总时长；大预览标题、歌手、专辑与状态信息居中排布。切歌、暂停和主题变化时刷新，保持隐藏时的低开销。
- 智能歌单新增已播放、未播放、最近 N 天播放／未播放筛选，支持最近播放、播放次数排序及结果上限，并提供三个可编辑预设。
- 队列新增标题、歌手与专辑搜索，可定位当前播放项；去重保留当前曲目及其他歌曲的顺序，可使用现有撤销恢复。
- 队列两侧留白对齐，保留可拖动滚动条；全局消息统一为随主题更新的紧凑浮动提示，支持关闭及撤销等操作。修复通知造成弹窗过度移动，以及长文件夹路径难以区分的问题。
- 新增音乐文件夹自动监测，将连续变化合并为增量刷新；扫描与手动操作、备份、时长校正串行处理，文件夹暂时失联时保留曲库。
- 新增 ReplayGain 曲目／专辑音量均衡，读取已有 FLAC、Vorbis、APE 或 ID3 标签。支持依据标签峰值限制增益，不改写歌曲文件。
- 新增逐曲播放进度记忆，可只对长音频或全部本地曲目启用。手动选曲时续播，自动切歌和循环仍从头开始；与会话恢复、书签及 A–B 循环分开处理。
- 大曲库搜索与艺术家／专辑索引分批计算，取消过期查询，仅保留并排序所需结果；曲库刷新中保持结果来自同一版本。
- 内置搜索增加完整请求截止与取消后的连接回收，避免慢响应和旧搜索继续占用资源；修复封面取消时的缓冲释放、卸载弹窗及多语言错误提示遗漏。

智能歌单入口位于歌单页；队列搜索与去重在播放列表顶部。自动更新曲库、ReplayGain 和逐曲进度记忆均可在“设置 → 曲库与播放”启用，默认关闭。长音频续播默认以 20 分钟为门槛，可选择 10、20、30 或 60 分钟。ReplayGain 的来源、回退与峰值边界见 [音量均衡说明](replay-gain.md)。

研究记录见 [本轮播放器源码研究](26.0.5-snapshot.1-player-research.md)，本机检查及交付记录见 [验证说明](26.0.5-snapshot.1-validation.md)。GitHub 正式版仍为 26.0.4。
