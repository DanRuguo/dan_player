# Dan Player 26.0.5-snapshot.2

完善曲库数据保护、歌词校准与日常播放体验。

- 新增曲库健康、目录重定位与迁移恢复，搬库保留歌单、统计和歌词。
- 新增歌词修订、锁定、历史版本与歌曲偏移，桌面歌词共用主程序。
- 提供播放详情、脱敏诊断、响度均衡和逐曲续播，改进播放稳定性。
- 扩展智能歌单，增加队列搜索与去重撤销，优化目录刷新和大库搜索。
- 同步全局播放模式，改进任务栏预览、图标、弹窗、多语言与动效。

提供 Windows x64 的 RCEIT.Inc 签名安装器、便携 ZIP 与校验文件；本预览不替换 26.0.4 正式版。
