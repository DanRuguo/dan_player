# Dan Player 26.0.5-snapshot.2

完善曲库数据保护、歌词校准与日常播放体验。

- 统一专辑分组，完善曲库健康、目录迁移与恢复，扫描支持取消。
- 增加批量标签预览与安全应用、局部封面重读，扩展智能歌单。
- 支持歌词修订、锁定、历史、偏移与本地全文检索，桌面歌词共用主程序。
- 增加队列搜索、去重、撤销／重做与指定条目停止，提供响度均衡、逐曲续播和播放诊断。
- 优化全局播放模式、任务栏、弹窗、多语言和动效，改善桌面歌词调色板首次打开响应。

提供 Windows x64 的 RCEIT.Inc 签名安装器、便携 ZIP 与校验文件；本预览不替换 26.0.4 正式版。
