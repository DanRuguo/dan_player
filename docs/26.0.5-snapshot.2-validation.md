## 合成曲库基线

Windows 11、i7-14700KF（28 逻辑处理器）、约 64 GiB 内存、Dart 3.13.1／Flutter test JIT。同一进程顺序执行 1千／1万／10万条虚构元数据，含 1% CUE；不扫描磁盘、不解码音频或封面。每组 21 个搜索样本，性能数字不等于真实播放器帧率。

初测定位到搜索 LRU 删除/重插后淘汰会反复扫描旧位置，改为固定 8192 容量的链表缓存。必要复测中，10万条索引重建由 33,245.579 ms 降至 8,987.983 ms；1万条为 890.661 ms。10万条搜索 p95 为 87.937 ms（初测 382.475 ms），进程峰值 RSS 约 372 MiB。只有一次前后样本，查询本身未改，不能把全部时差归因于缓存修改。

缓存、异步搜索与规模用例合计 11 项通过；一个新用例按文件名排序的 fixture 已修正并单独复测。日志 `scale-baseline.log`、`search-lru-scale-recheck.log`、`search-lru-regression-final.log`。复现：设置隔离 `DAN_PLAYER_DATA_DIR` 后执行 `flutter test --no-pub --dart-define=DAN_RUN_LIBRARY_BASELINE=true test/library_scale_baseline_test.dart --reporter expanded`；默认跳过，不加入每次例行全量检查。

## 详细功能与使用变化

本次为 Windows x64 预览发行，提供 RCEIT.Inc 签名安装器、便携包及 SHA256SUMS。安装版运行 Setup；便携版请先退出旧播放器，完整解压到新目录后运行 `Dan Player.exe`。稳定版仍为 26.0.4。

- **统一程序入口**：桌面歌词改由同一个 `Dan Player.exe` 启动独立进程，共用运行库、AOT 和字体；包内不再提供独立 `desktop_lyric.exe`。保留歌词的独立窗口、置顶、穿透及外观设置逻辑。修复设置页版本显示未同步，加入构建前版本一致性检查。
- **曲库与数据保护**：本地曲目获得独立稳定 ID；旧统计只在唯一匹配时归属，歧义记录与原始总额保留。新增目录重定位、来源状态与轻量健康检查；备份恢复保留缺失条目及重复歌单位置，自定义排序采用原子保存和损坏保护。
- **歌词校准与锁定**：保存原始副本、人工修订和历史版本；支持歌曲偏移、确认锁定及不再查找。主窗口、迷你播放器和桌面歌词共用校准后的时间轴，迟到请求不会覆盖新选择。
- **播放与诊断**：区分主动停止、自然结束、CUE 段结束与播放故障，过滤过期会话事件。歌曲信息内提供折叠播放详情，区分请求与可检测的实际输出及增益，并可导出脱敏诊断。
- **桌面体验**：统一图标主题、紧凑提示和分档动画，加快返回；优化队列留白、封面与任务栏预览。歌词校准和文件夹管理采用分组布局、居中标题和充足间距，适配长路径、窄窗口与大字号，补齐新功能的英日韩提示。播放模式全局同步，歌单首页移除无歌曲可操作的模式按钮。
- **日常使用**：提供听歌记录智能歌单、队列搜索与可撤销去重、文件夹自动刷新、ReplayGain 曲目／专辑均衡及可选逐曲续播；旧统计归属未知的歌曲不会被当成“从未听过”。

### 使用变化

- 随机与循环可以同时启用，各页面状态同步；按钮只切换模式，不开始播放。歌单首页不显示这组控件，歌曲页继续保留。
- 桌面歌词仍从播放器按钮或设置打开，任务管理器可能看到两个 `Dan Player.exe` 进程，这是预期行为。请将本便携包解压到新目录，整体保留 `data/`、BASS 和运行库，不要仅复制 EXE；原资料路径与歌词设置保持兼容。
- 搬目录后打开「设置 → 曲库与播放 → 曲库健康与搬迁 → 重定位目录」，填写旧、新目录并预览。确认后播放器退出，下次启动先备份并应用关联。仅重新关联已经搬好的文件，不移动音乐。
- 迁移快照保存在资料目录 `library_migrations/<批次>/`。恢复会成组撤销该次迁移后的相关资料变化；迁移后新建的权威资料文件移入同批次 `displaced/` 保留。不会把已搬动的音乐搬回旧目录。
- 原生标签写入成功且同步记录落盘后，关系同步失败可在重启时继续，恢复过程不会重复写标签。文件写入返回与记录落盘之间仍存在很短的崩溃窗口，不能视为完整的磁盘事务。
- 歌词详情的「歌词校准与锁定」入口可保存偏移：**+500 ms 表示歌词晚显示 500 ms**。编辑默认写应用内副本；覆盖导出 LRC 需明确确认。CUE 修订属于独立片段。
- 播放详情不会将独占开关等同于 Bit-perfect。未知输出字段保持未知；解码或段结束不作为物理设备已排空的证明。

### 兼容与边界

保留 Flutter + Rust + BASS、原有歌单与在线来源。稳定身份存于 `track_identities.json`，人工歌词存于 `lyric_documents.json`；请随播放器资料一同备份，不仅复制可重建的索引。

此次未实现自动指纹找回、同名专辑分组重写、物理输出无缝证明、任意工作区或 NAS 接入。原生扫描仍安全完成后提交，关闭窗口不代表取消扫描；暂时离线的来源保留旧完整索引，未改成部分来源提交。

本包使用与 26.0.4 相同的 RCEIT.Inc 自签名证书。签名不等于公共受信任证书或 SmartScreen 信誉，Windows 仍可能提示。安装器与便携包使用同一批程序文件，安装器另附 `.exe.sha256`；既有升级校验保持启用。
