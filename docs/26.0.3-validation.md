## 发布前修订：工具栏、设置与托盘重绘（2026-08-30）

- 音乐、歌单和分类操作栏共用真实字体测量、内边距和触控高度，兼容四语、窄窗口及放大字号。
- 五类设置统一圆角底色、图标、标题与控件间距；保留原设置值、保存流程和“不可见时暂停视觉更新”的选择。
- 托盘悬停改为内存完整帧合成后一次提交，只使受影响菜单行失效，不再清空并重画整个可见菜单；复用有界缓冲区，关闭释放，内存预算不足时使用系统菜单。模糊仍只在打开时采样一次，不因鼠标移动重新采样。
- 本轮托盘悬停检查覆盖原子呈现、局部裁剪、失效绘图目标恢复与 GDI 生命周期。测试只使用内存合成像素，不读取桌面或私人音乐。
- 任务栏小缩略图与桌面 Peek 分开计算尺寸：Peek 保留歌曲卡片，按客户区等比例放大居中，临时图像限制为 16 MiB，超大窗口按比例受限，不裁切文字。放大改善可读尺寸，不宣称增加源图的真实细节。
- 隐藏 HWND 诊断确认最小化后客户区可能为零或约 199×34 的图标尺寸。Peek 现缓存最后一个真实非最小化客户区；启动即最小化时，从还原窗口尺寸和实际边框信息推导回退大小，不用微小客户区作画，也不以估计值污染真实缓存。读取路径不变更窗口或人工触发 `WM_NCCALCSIZE`。
- 切歌、封面配色和字体更改使用新完整帧替换旧帧，不反复清除 DWM 预览属性；晚到的旧发送/清理失败不能覆盖新状态。原生短暂失败保留最新源并有限重试，退出和关闭预览终止重试。
- 当前展示树移除旧真实截图，使用生产 Flutter 组件和虚构数据的离屏渲染；真实截图的恢复副本仅在仓库外保存。历史提交、版本标签与旧 Release 保留，不宣称历史副本已删除。

- 纯移动、缩放及 `WM_EXITSIZEMOVE` 不再重建效果或执行整窗擦除；最大化/全屏相关的边框修复与材质重建分开。原生父窗增加 `WS_CLIPCHILDREN`，背景擦除不覆盖 Flutter 子窗，防止停下拖动时暴露黑色背景。瞬时接口失败可在激活/显式配置时重试，避免主题/样式消息形成重试循环。
- 侧栏透明且没有独立描边、阴影、底色或二次模糊；标题栏没有额外底色、分隔线。拖动区域和窗口按钮保留，主内容外沿不再有不同遮罩造成的拼接色差。
- 仅主要内容面板保留统一 16px 圆角、细描边及轻微立体阴影。阴影附近允许自然的局部明暗变化，不是独立遮罩。
- 顶部歌曲胶囊为 32 个逻辑像素高，在 48 高的标题区内上下各留 8；移除主内容面板额外的顶部 8，避免胶囊下方间距加倍。布局不依赖 Win10/Win11 专属偏移。胶囊文字缩放最高 150%，其他页面的辅助功能文字缩放不受影响。
- 歌曲详情使用所查看歌曲的专辑背景；全屏播放/歌词页继续使用当前歌曲的专辑背景。详情背景在自己的面板内裁剪，不会覆盖主窗口侧栏和标题。封面失败时使用可读的面板底色，过期请求不会串图。
- “专辑封面动态配色”只影响主题色，不影响主窗口背景来源；原生层只同步明暗模式。设置页显示窗口背景状态及回退原因。
- 高对比度下，透明窗口控件的文字与系统背景成对处理，不改变主内容自身主题。窄窗抽屉使用自己的配对前景/背景，高对比度下改为实色；切换后抽屉状态保留。

## 功能边界

- 联网收藏指将来源和歌曲标识持久保存到本机总乐库/歌单，不是 QQ、网易云账号收藏同步，也不是独立的云端收藏夹。
- QQ/网易匿名接口当前未提供可靠的官方下载权限，界面会禁用下载并说明原因；搜索、播放及加入总乐库不依赖下载能力。
- 已有在线歌词来源选择、歌词动画、桌面歌词和本地同名 `.lrc` 编辑；**选中在线歌词直接导出、独立的本地歌词文件夹管理器尚未实现**。
- 语种统计优先语言标签，其次使用保守的文本线索；不是对音频做人声语言识别，不确定的歌曲归入“未识别”。

项目自有的主 EXE、Rust DLL 和桌面歌词 EXE 使用 `CN=RCEIT.Inc` 的 SHA-256 代码签名；证书有效日期为 **2026-08-27 至 2027-08-27**。
证书指纹：`E11D145A3C0D7298F4D3E96BADC497E360CAF510`。

这是本地自签名证书，不是公共 CA 证书。Windows 默认不信任其根，可能显示未知发布者/SmartScreen 提示；本次没有修改可信根或关闭安全检查。
没有使用可信时间戳服务，不承诺证书到期后仍可获得信任。私钥未放入代码或发行包；第三方运行库保留原厂签名。

请完整解压便携 ZIP 到新目录，关闭旧播放器后运行新目录的 `Dan Player.exe`，不要仅复制主 EXE。
必须保留同目录的 `data`、`BASS`、`desktop_lyric` 及 DLL。包内与 ZIP 旁各有 `SHA256SUMS`，用于核对文件完整性。
不要把开发测试用的 `DAN_PLAYER_DATA_DIR` 设置用于日常运行；正常启动会沿用原来的应用数据目录。
