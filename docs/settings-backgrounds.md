# 设置分类、自定义图片和可选背景动态

## 设置入口

设置页保留所有原有项目，整理为五组：

- 曲库与播放：文件夹、刷新、艺术家分隔符、恢复会话、倍速与独占输出。
- 联网与歌词：内置歌源、歌词候选、多自定义歌源 API、主歌词弹性与桌面竖排选项。
- 外观与背景：三场景背景、主题配色、系统主题与字体。
- 桌面与快捷键：托盘/关闭行为、任务栏播放控制、实际快捷键说明入口。
- 更新与关于：检查更新、反馈问题。

宽窗口使用分类按钮；窄窗口或大字号使用可滚动下拉菜单。分类首次访问时才挂载，之后保留该组的滚动位置和未保存输入；未显示组关闭焦点遍历和 ticker。未进入的设置组不会提前构造播放服务、发起网络请求或读取背景图片。切换分类不迁移数据库或改写原设置键。

## 背景来源与透明度

主窗口、歌词播放页和迷你播放器仍独立设置。主窗口/迷你默认是真实 Windows 窗后背景，歌词页默认专辑封面。新增“自定义图片”，不会替换这些默认值。

- 窗后背景由 Windows 合成器采样，**不随专辑切换**；没有桌面截图，也不在动画帧中调用 DWM。
- 专辑封面跟随歌曲；自定义图片保持用户选定的图片。
- 动态主题配色、背景来源和轻缓动态是三个独立控制项。
- `opacity` 仍表示可读性遮罩的不透明度。UI 的“背景透明度”显示 `1 - opacity`，数值越大背景越明显，文字/按钮不变透明。
- 高对比度使用实色背景，不加载图片、不运行背景动态。平台不支持原生玻璃时沿用既有回退。

## 托管图片与数据安全

用户通过文件选择器明确选择静态 PNG/JPEG/WebP/BMP。导入会检查文件字节、格式、尺寸和解码结果；GIF、APNG和动画WebP不作为动态壁纸导入。取消选择不是错误。

输入最多20 MiB、4000万像素。通过校验后，只为背景生成最长边2048像素、最多4百万像素的PNG渲染副本，小图不放大。原始图片不会被移动、覆盖、写标签或删除。此限制只针对背景副本，前景专辑封面继续使用现有DPR清晰度管线。

副本位于应用数据目录的 `background-images`，文件名是内容SHA-256加`.png`。设置仅保存ID和显示名称，不保存任意文件路径/URL。相同内容复用，单次导入串行执行；唯一临时目录内写入并flush，成功rename后才发布新选择。验证、IO或导入失败保留原选择；设置保存失败会明确提示当前选择只对本次会话生效。

托管副本限制为24张、合计96 MiB，达到上限时要求显式清理而非静默删除。点击“清理未使用副本”只会删除本目录中符合托管ID的普通文件，不递归处理目录、未知文件、链接、原图片。清理保留三场景的当前/未激活选择，以及`settings.json`和存在的`.bak`中的引用；读取已保存配置失败时**不开始删除**。移除图片选择、还原背景本身不会立即删除副本。若要恢复历史配置，请同时保留所引用的托管副本。

内存中只保留最多6个文件provider查询，不保留原图字节。实际图像解码由Flutter的有界图像缓存和现有`ArtworkSize`物理像素分档处理。自定义背景的横竖图按`BoxFit.cover`采样、DPR变化更新解码键；专辑背景保留512像素采样，主题取色和前景封面不受影响。导入的4MP是缩略图**解码输出**上限，不代表原图codec的总工作内存峰值。

设置卡片内的图片预览也根据实际宽度、112逻辑像素高度和当前DPR分档采样，不将固定小缩略图拉伸铺满宽屏。DPR更新不重新读取托管文件，等待清晰版本时保留已显示图像；横竖图与小原图仍受同一解码预算/不放大策略约束。

## 轻缓动态

默认关闭，仅对图片背景生效。独立实现缓慢平移/小幅缩放已解码的图片；不是音频频谱、视频壁纸或Windows玻璃，也没有引入mesh/shader依赖。

36秒一个平缓循环，时钟上限20Hz。只有局部Transform重建，静态图像/模糊层放在RepaintBoundary内，遮罩、正文和操作控件不参与移动。暂停播放、窗口隐藏/最小化、非当前路由、TickerMode关闭、系统/MediaQuery减少动态效果或高对比度时停止。直接订阅原生可见性通知，即使隐藏窗口不再产出Flutter帧也会取消定时器。恢复时延续冻结位置，不补跑后台经过的帧；销毁组件移除监听和定时器。

专项自动测试覆盖旧偏好兼容、三场景隔离、图片校验/配额/去重/原图不变/失败恢复、存储路径限制、保存引用保护、真实codec+DPR横竖图采样、分类滚动/输入/键盘/大字号、生命周期/暂停/隐藏/无障碍门控及原图像管线回归。测试只使用工作区内合成文件、内存偏好与纯控件，不读取真实曲库，不启动GUI或音频。
