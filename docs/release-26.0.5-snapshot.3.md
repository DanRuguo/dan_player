# 26.0.5-snapshot.3

完善曲库整理、歌词与播放体验，作为 26.0.5 正式版前的候选预览。

- 新增个人整理、评分标签、智能条件组、歌单回收与 M3U8 差异合并。
- 完善曲库健康、目录迁移、批量标签与升级备份，优化扫描和大库搜索。
- 支持歌词修订、锁定、校准与全文检索，桌面歌词共用主程序，改进调色板响应。
- 扩展队列保存与撤销、全库书签、定次 A–B、EQ 预设、响度均衡及逐曲续播。
- 统一主题控件与自适应弹窗，完善任务栏预览、播放防休眠和四语言显示。

提供 Windows x64 的 RCEIT.Inc 签名安装器、便携 ZIP 与校验文件。
