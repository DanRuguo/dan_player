# 26.0.4 snapshot1 验证说明

本次按预览版发布；26.0.3 仍为最新稳定版，旧 tag、Release 和资产不变。简短更新内容见 [发行说明](release-26.0.4-snapshot.1.md)。

## 本次范围

- 主播放条翻译、上一首/下一首/队列，直接拖动原有色块的竖向分界线；不增加底部滑条。拖柄采用像素对齐的实心圆头短线，不使用渐变或光晕；松手约 100 毫秒整体淡出，不因鼠标驻留或保留键盘焦点而常驻。保留键盘调节，切歌、缓冲及取消不会误提交旧位置。100%、125%、150%、200% 渲染下的线宽、实心像素和两端边界均有回归检查。
- 歌单详情使用图标式视图选择，顶层仍保留文字；宽窄布局与大字体回归使用真实 Flutter 控件。
- 明亮/深色/跟随系统共用一个持久化字段，兼容旧设置；系统模式实时响应平台亮度，手动模式不被覆盖。
- 托盘使用应用字体及 Material Symbols，文字加粗、图标胶囊统一；Peek 使用独立高分辨率卡片，不再拉伸小缩略图。
- 暂停自定义外窗圆角，移除生产窗口的裁剪控制器接入，外框处理回到 26.0.3 路径；内部控件圆角不变。退出先隐藏再清理，原生资源销毁前另有隐藏保护。
- 标签保存保留非编辑字段、语言、附加图片和音频数据；编辑成功与曲库同步失败分开报告，重试不重复写入同一修改。
- 曲库增加增量刷新，依据路径、文件大小与高精度修改时间复用未改变的记录；保留完整刷新。首次迁移旧索引会补读指纹，目录不可访问时不覆盖旧索引。
- 安装器验证实际安装载荷、手动路径、升级、回滚和中断恢复。仅触及清单列出的程序文件与用户选中的快捷方式，用户曲库数据不属于安装载荷。
- 更新支持持久化稳定/预览通道、下载前确认和下载后确认升级；不在后台静默安装。哈希、系统签名信任、同发布证书与接管握手均通过后才退出播放器，失败保留手动入口。

## 验证与边界

自动化日志保存在工作区外的私有 QA 目录，不提交原歌曲、完整路径、封面或私人歌单。测试只对音乐副本写入，原文件只读核验。公开图片来自虚构数据的实际组件离屏渲染，不使用用户桌面截图。

本快照不启用自定义外窗裁剪，也不再显示该设置；旧偏好字段仅保留兼容，不触发窗口操作。没有回退托盘、歌曲预览和其他功能修复。

没有启动已安装播放器或进行真实桌面/DWM 人工截图验收。隐藏 HWND、像素及控件测试不能替代所有设备、显卡或 Windows 版本的实际操作；不承诺绝对无缺陷或任意硬件上的“性能最优”。

“偶发按钮变深但没有动作”的原现场尚未完整复现，但补充验证了两条具体原因：迷你 Navigator 被移除时弹窗 Future 不完成，令快捷键说明的全局打开锁不释放；播放条的默认鼠标拖拽容差仅 1px，会抢走按钮点击。均有修改前失败、修改后通过的隔离回归。另有弹出菜单异常复位、窗口状态查询失败/超时解锁和保存后同步重试检查，不宣称所有偶发无响应都有同一个原因。

后续复查又修复两处独立路径：普通窗口的帮助弹窗被保留在后台时，不再阻止迷你窗口打开自己的帮助；管理文件夹读取索引目录失败后会恢复编辑、关闭和重试入口，不再卡在所有按钮禁用的状态。两项均有修改前失败的隔离回归，未引入对仍可能提交的原生操作强行超时解锁。

发布前另补上原生关闭失败的退出重试：并发退出等待同一操作，关闭失败释放退出锁，更新页能显示异常并重试退出，不重复启动安装器。清理后的播放资源不会假装恢复；这里只保证错误可见、仍可再次退出。

歌曲可播放并不代表当前容器支持安全改写标签。ASF/WMA 或混合容器会明确拒绝编辑并保留原文件；不会自动转码、改扩展名、改权限或去除只读属性。

增量刷新不逐首计算音频内容哈希：若外部工具改动内容但刻意保留文件大小和修改时间，请使用完整刷新。元数据暂时读取失败的项目保留旧记录并标记待重试；无变化的封面缓存不会全部清空。刷新与歌曲信息保存共用操作级互斥，刷新视图销毁不会取消后台扫描或提前释放门禁，扫描及重载仍会完成。

安装器修复了正常 Flutter 载荷中的 `native_assets.json` 被安全白名单误拒绝的问题，打包前使用同一生产验证器校验载荷。只读核验确认旧版便携目录可被识别为原位升级目标。明暗主题、按钮背景与目录行对齐使用专用非交互桌面的安装器自身控件离屏渲染验证，未使用用户桌面截图；125% 缩放下路径框与浏览按钮的垂直中心差为 0 像素。

按钮裁切不能仅靠父容器内的坐标判断：扩展验证复现了正文兄弟区域覆盖底部按钮上缘、完成页动作越入左侧图区的问题。修复恢复 Inno 原生扁按钮尺寸与页面排布，完成动作约束在右侧内容列；新增检查覆盖品牌、目录、进度、完成阶段的绘制遮挡。

安装器缩紧整体高度，以透明 RCE 和 DanRuguo 标识替换默认安装图，自动选择明暗版本；浏览按钮与路径框居中，完成动作等宽、居中且不越入品牌列。最终验证包括明暗主题 × 7/9/11/14pt 字体的 8 组完整流程、40 个阶段的控件绘制与边界检查，未发现裁切或重叠。测试桌面实际为 125% 缩放；字体压力测试不等同于在多种系统 DPI 下实际运行。

完成按钮在保持 Inno 原生尺寸和底部位置的前提下，对齐完成页内容列；六类按钮均使用粗体。实际 HFONT 的 160 次字重/文字边界检查通过。播放条拖柄另覆盖奇数物理窗口宽度造成的半像素全局偏移，避免只在原点渲染清晰、实际居中后又变模糊。

云端干净环境另暴露了按钮像素测试的两处误报，并在本地用不同字号复现：背景取样点可能落在字形上，小字号抗锯齿也不一定产生纯黑或纯白像素。追加回归分别检查空白背景、边缘与真实文字，并记录失败原因；生产绘制和安装安全检查保持不变。

歌曲副本首写验证按三批原字节一致的输入汇总：618 + 26 + 2 = 646 首成功，压缩音频数据（MP4 为 mdat）逐字节保持不变；其余 4 个 ASF/WMA 和 1 个前置 ID3/MP4 组合安全拒绝，失败副本全文不变。原曲 651/651 的 SHA256 与最初清单一致。这是分批首写证据，不宣称最终代码单次重写过全部曲库。

Windows 文件属性与播放器原生回读不是同一解析器：646 首成功中，Windows 的三个字段有 606 首完全匹配；19 个实际 MP4 但名为 .mp3 的文件未正常展示，20 首的 Windows Artist 取自保留的 AlbumArtist，另 1 首未暴露这些字段。播放器的请求字段回读验证通过；没有擅改扩展名或 AlbumArtist 来迎合资源管理器。

本次安装器和自有二进制使用现有 RCEIT.Inc 自签名证书，不添加任何受信任证书。它不是公共 CA 签名，Windows 仍可能提示未知发布者，安全升级入口会在系统不信任签名时退回手动安装。第三方运行库保持原字节、已有签名与许可证。
