- 新增个人评分／标签／最近添加、智能条件组、歌单回收与独立视图、M3U 差异合并、命名队列、全库书签、定次 A–B、精确定位、批量歌词、用户 EQ 和播放防休眠。旧歌曲日期按用户要求用文件创建时间兜底；新歌曲使用成功入库的提交时间。
