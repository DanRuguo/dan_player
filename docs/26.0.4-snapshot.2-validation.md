# 26.0.4 snapshot2 验证说明

本次按预览版发布；26.0.3 仍为最新稳定版，历史版本和 snapshot1 均保留。简短更新内容见 [发行说明](release-26.0.4-snapshot.2.md)。

## 使用边界

- 本地缓存备份保存曲库索引、歌单、设置、统计及缓存资源，不复制音乐文件。
- 在其他电脑恢复前，应先导入包含尽量相同歌曲的文件夹；无法可靠匹配的歌曲引用会跳过并显示数量。
- 空目标目录会直接作为缓存目录；识别到旧缓存时必须确认替换；非缓存目录会使用安全的 `Dan Player` 子目录。
- 缓存恢复先写入暂存目录，并在下次启动时切换；切换失败会保留原缓存。
