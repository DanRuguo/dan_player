# Dan Player 26.0.4

新增常用歌单与本地播放功能，完善联网来源和 Windows 桌面交互。

- 新增智能歌单、CUE 分轨和播放／A-B 书签，队列整理支持撤销。
- 扩展批量操作与 M3U8 导入导出，改进排序、封面和曲库刷新。
- 完善联网搜索、歌词与评论，新增网易增强 API 适配。
- 美化搜索分类、歌词按钮与进度条，修复迷你歌词和弹窗布局。
- 增加 Windows 右键快捷任务、单实例与卸载入口，改进启动和安装升级。

提供 Windows x64 安装器、完整便携 ZIP 与校验文件。旧证书版本请手动下载安装器升级。
