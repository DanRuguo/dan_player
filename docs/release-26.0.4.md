# Dan Player 26.0.4

26.0.4 新增智能歌单、CUE 分轨、队列撤销、标准歌单交换与播放书签，完善批量操作、联网来源、歌词体验和 Windows 桌面交互。

## 歌单与播放

- 统一多选菜单：播放所选、随机播放、下一批播放、追加队列、加入歌单、导出 M3U8、复制歌曲信息/本地路径、全选与反选。按显示顺序执行，保留重复曲目；曲库刷新不再清空选择。
- 新增 M3U/M3U8 导入及 UTF-8 M3U8 导出，可选相对路径，保留顺序、重复项和 EXTINF 信息，支持跨盘与 Windows 网络共享路径。导入先预览，不复制音乐，不递归读取嵌套歌单。
- 播放详情“更多 → 播放书签”保存命名的时间位置或 A-B 片段，支持恢复、重命名、删除及跨次启动保留。本地歌曲的 A-B 循环可从队列顶部设置。
- 队列可以移到下一首、移除条目、定位当前曲、仅保留当前曲，以及保存为新歌单。
- 新增智能歌单：保存关键词、艺术家、专辑、格式及最短/最长时长条件，曲库刷新后按规则更新结果，支持排序与常用播放操作。
- 新增 CUE 分轨导入：整张音频以独立曲目播放，分轨有自己的进度与边界，保存到普通歌单并可恢复队列；不拆分原始文件。
- 队列整理最多撤销 10 步，保留当前歌曲、暂停状态与进度；切歌或替换整个播放队列后清空历史。

## 联网与评论

- 更新 QQ 搜索兼容方法，修复本轮遇到的 2001 服务状态和不透明评论 ID 解析错误。不同平台按实际能力显示评论列表、热门或最新排序。
- 新增网易云增强 API 的专用适配器及默认关闭的预设，支持搜索、详情、封面、歌词/翻译、热门/最新评论、播放与独立下载解析。使用前需部署或填写实际服务地址。
- 对“卡农、稻香、Good Time”按来源与固定录音核实能力。增强 API 的《Good Time》原唱当前只有 30 秒试听，播放器不会把它当完整歌曲；《稻香》未命中已确认的周杰伦原唱，未用翻唱冒充成功。
- 搜索不逐首追加详情请求；请求可取消并有时间及体积上限。搜索按钮、清空和忙碌反馈补全，旧响应不会覆盖新结果。
- 默认歌词区分未提供歌词、连接/解析失败和保存失败；自动匹配检查版本与时长，手选保留版本提示，酷狗不再以明显属于其他歌曲的歌词候选兜底。
- 使用《結想は花となる short ver.》96 秒录音排查搜索、歌词、评论与封面：本次未找到可确认的同版结果，195 秒完整版的可用结果单独记录，不自动套用到短版。

## 界面与 Windows

- RCE 和 DanRuguo 启动画面各缩短 0.5 秒，品牌展示总计约两秒。
- 搜索分类改为带图标的圆角分段导航；歌词详情播放按钮改为透明描边。
- 进度手柄改为圆角短竖条，加入悬停/拖动形变、时间预览和松手回弹；尊重减弱动画设置，隐藏页面停止进度监听。
- 修复迷你歌词切换时新旧文字重叠，以及详情音量监听资源未释放。
- 修复窄窗口下第三方 API 能力标签的长英文溢出，保持能力名称完整可读。
- 任务栏/开始菜单右键提供主窗口、播放暂停、上一首、下一首和迷你播放器。重复打开复用已有实例；修复冷启动快捷任务被会话恢复吞掉。
- 设置 → 更新与关于 → 应用管理可打开本安装的卸载向导，便携版提供程序目录入口。

## 下载与升级

提供 Windows x64 安装器、完整便携 ZIP 和 SHA256SUMS。便携包需完整解压后运行 `Dan Player.exe`。

本版自有程序使用新的 `RCEIT.Inc` 十年自签名证书（2026-09-05 至 2036-09-05）。它不等于公共 CA 信任或 SmartScreen 认证，Windows 仍可能提示。旧版固定了旧证书指纹，从旧证书版本升级请手动下载本版安装器；新安装器支持原位升级。安装器不会自动安装信任证书。

公开 API 的可用性随曲目、地区及服务状态变化，搜索成功不表示具有完整播放或下载权限。标准歌单交换和书签限定本地音乐。
