# Dan Player 26.0.3

Windows x64 稳定版。历史提交、版本标签与 26.0.1 / 26.0.2 Release 保留。

## 更新重点

- 统一音乐、歌单、分类工具栏和五类设置的高度、间距、圆角、图标与主题色；适配中英日韩、窄窗口和放大字号。
- 完善歌单列表/网格/圆形视图、可选曲库分栏、桌面歌词个性化，以及“不可见时暂停视觉更新”开关。
- 修复弹窗、通知、联网信息选择区、顶部歌词和分段按钮等交互布局；桌面歌词外观窗口独立显示、圆角与复开缓存。
- 修复托盘菜单悬停时的逐步重绘，使用完整帧合成及局部刷新；切歌状态、字体和图标颜色同步更新。
- 修复切歌、换色时任务栏歌曲卡片反复撤销后重建的问题，最新完整帧直接替换，陈旧请求不能覆盖当前歌曲。
- 桌面 Peek 保留歌曲卡片，但按播放器窗口尺寸等比例放大、居中显示；最小化时保留正常窗口尺寸，启动即最小化时使用还原尺寸回退。任务栏小缩略图独立缩放，修复桌面卡片过小难以阅读的问题。关闭歌曲预览可恢复系统窗口预览。
- 展示图片改为真实 Flutter 组件搭配完全虚构数据的离屏渲染，不包含私人曲库截图。历史版本内容未重写。

想先了解界面与特色功能，可从 [项目首页的图文介绍](https://github.com/DanRuguo/dan_player#readme) 开始；展示歌曲、歌词与歌单均为虚构演示内容。

## 下载与使用

下载 `DanPlayer-26.0.3-windows-x64.zip` 和同页 `SHA256SUMS`，核对 SHA-256 后完整解压到新目录。关闭旧播放器，再运行 `Dan Player.exe`；不要只复制 EXE。

自有二进制使用 RCEIT.Inc 本地自签名证书，**不是公信 CA / SmartScreen 认证**。未修改系统信任设置，第三方运行库保留原始字节。

自动化覆盖功能、交互、四语/明暗/大字号布局、绘制和资源生命周期；这不等同于所有 Win10/11 硬件、驱动与联网服务组合绝对无缺陷。详细结果见 [验证说明](https://github.com/DanRuguo/dan_player/blob/v26.0.3/docs/26.0.3-validation.md)。
