## 有限真实接口取样

按用户建议查询“卡农”，请求不登录、不带账号 Cookie，不实际播放或保存整首歌曲：

- 酷狗：“卡农（经典钢琴版）/ dylanf”（300 秒）和“Canon（钢琴版）/ Jason Piano”（263 秒）均取得完整时长音源；媒体服务器返回 HTTP 206，仅读取各 4 KiB。
- QQ：“Canon in D Major / dylanf”搜索成功，下载接口 HTTP 200、外层 code 0，但逐曲 result=-14，无下载 URL。
- 网易：“卡农（经典钢琴版）/ dylanf”搜索成功，下载接口 HTTP 200、外层 code 200，但逐曲 code=-105，无下载 URL。

QQ／网易没有取得地址，因此没有发起媒体下载。这不等于所有歌曲都不可下载，也不据未知业务码猜测具体登录或付费原因；界面允许尝试并按实际结果提示。一次取样不能保证接口长期可用。

## 发布与数据边界

主程序、桌面歌词和安装器按对应源码变化构建；安装器原生辅助组件若未变化则复用经过验证的构建，不重复编译。发布前检查字体、来源清单、签名和 SHA-256，安装器与 ZIP 都使用同一最新 payload。

第三方 API 配置、稳定歌曲 ID、收藏与歌单保留；删除或清空配置不会在重启时自动复活。未完成下载写入独立临时文件，失败不会覆盖原文件。缓存备份不复制音乐文件，缺失封面回退到歌曲封面或默认图。
