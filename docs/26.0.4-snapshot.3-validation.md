# 26.0.4 snapshot3 验证说明

本次按预览版发布；26.0.3 仍为稳定版。snapshot3 验证并上传完成后，将替换 GitHub 上旧的 snapshot2 预览 Release。简短更新内容见 [发行说明](release-26.0.4-snapshot.3.md)。

## 使用边界

- 本地缓存备份保存曲库索引、歌单、设置、统计及缓存资源，不复制音乐文件；跨设备恢复前应先导入包含尽量相同歌曲的文件夹。
- 无法可靠匹配的歌曲引用会跳过并显示数量；缺失的自定义封面会保留原引用，并自动回退到第一首可用歌曲封面或全局默认图。
- 空目标目录可直接作为缓存目录；识别到旧缓存时必须确认替换；其他非空目录会使用安全的 `Dan Player` 子目录。
- 联网歌词候选仅填入编辑框，由用户确认并保存；“加入歌单”在写入期间禁止重复关闭或提交，重复歌曲不会触发无效持久化。
