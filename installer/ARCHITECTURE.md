# 独立 Windows 安装器

当前实现：**Inno Setup 7.1.0 Unicode x64 + 自有原生事务补强 DLL**。版本、展示版本和目录名均由根 `pubspec.yaml` 读取。离线安装器不下载载荷、不安装编译器或证书；发行签名由构建脚本显式选择，发布操作由主发布流程负责。

## 为什么不是 Flutter 安装器

Flutter 可以实现 Material 安装界面，但 Windows 发布还需要 DLL 和 data，单 EXE 仍需可靠引导/安装引擎。本轮采用成熟 Inno 的内嵌载荷解压与安装流程，避免另造解压器和引导运行时；UI 是原生 **Material-like**，不是 Flutter Material 组件，也不宣称完整 Material Design 实现。[Flutter 部署说明](https://docs.flutter.dev/platform-integration/windows/building)

评估过 WiX、NSIS、Velopack。最终没有引入 WiX/Burn/MSI 或其商业/EULA依赖，没有另一个备用安装路线。Inno 免费许可证允许包括商业在内的用途；原始运行时未修改，保留它已有的版权及网站信息。许可全文见 [Inno Setup 署名及许可](licenses/INNO-SETUP.txt)，官方项目为 [jrsoftware/issrc](https://github.com/jrsoftware/issrc)。

## 界面与路径

- 单个配置页包含最终路径、父目录选择、独立的桌面/开始菜单快捷方式选项。随后只有安装进度和结果页。
- 父目录默认追加 `danplayer_<SemVer>`；验证出的旧安装位置优先。同一会话内一旦手动编辑最终路径，父目录变更和迟到的旧版检测都不再改写它；空手工路径也不会被偷偷替换。
- 原生 Windows BUTTON 保留键盘、焦点与辅助功能语义。沿用 Inno 的较扁按钮高度和底部位置，GDI+ 仅绘制小圆角（6个基准单位）及主题强调色；标题居中，高对比保留系统绘制。六类按钮使用真实粗体 HFONT，字体家族与字号不变。底部按钮不侵入正文 notebook；完成页动作在右侧文案列居中纵排，同宽不超过240个基准单位及列宽，真正“完成”按钮经屏幕坐标转换后共享该列中心，不改变其原生高度。不是仅设置 `WizardStyle` 后声称 Material。
- 窗口采用 `WizardSizePercent=110,100`，由 Inno 一起计算正文和底部区域，减少空白而不手动上移 footer。默认纸箱插图改为原始透明品牌图：目录/进度页右上角为小 RCE，完成页左列为适度的 RCE 与 DanRuguo 组合，不改变原位图。
- 明暗方案在安装器启动时读取 Windows 设置；配置页和品牌页使用同一浅色/深色背景。按钮圆角外与 Logo 透明区域绘制实际父控件背景，避免 VCL 主题背景与固定白底不一致。可用按钮文字按实际底色保护对比度；路径输入框保留原生高度，与父目录按钮垂直居中。[Inno 主题行为](https://jrsoftware.org/ishelp/topic_setup_wizardstyle.htm)
- 现有透明 RCE / DanRuguo PNG 在同一背景上各约0.8秒，交叉过渡总计1.6秒。系统减少动画或高对比时不做淡入淡出；静默安装跳过品牌页。
- 私有载入现有萍方字体，读取内部 family，GDI实测为 `.萍方-简`；不向 Windows 字体目录安装字体。加载失败保留系统字体。

## 有界安装与恢复

Inno 原生覆盖安装不能等同于完整恢复旧文件。本项目明确添加以下补强，不声称引擎原生保证全部事务语义：

1. 只接收已经审计的便携目录。生产打包核验产品/来源/版本与每个 SHA256SUMS 条目，逐文件生成内嵌清单；压缩前用同一内嵌 DLL 的纯只读 `DP_ValidateManifest` 检查运行时路径白名单、重复项与预算，不初始化目标或事务，拒绝不可安装的载荷。安装时没有下载。
2. 默认仅当前用户，无自动提权。禁止盘根、系统/用户数据位置、Program Files、UNC/设备路径、ADS、路径穿越、重解析点和硬链接。正在使用的文件提示正常退出播放器再重试，不强制结束进程。
3. 安装前对清单涉及的原文件、精确两个快捷方式及该产品HKCU注册信息备份。便携旧版必须匹配关键主程序、AOT、helper校验；无关非空目录拒绝，未知文件保留。
4. 恢复日志位于目标旁专用 `.<目录名>.danplayer-recovery`。原文件按SHA256备份、落盘后才允许Inno写入；仅退休旧清单确认且未修改的过时文件。
5. 固定跨版本 `SetupMutex` 防止同会话并开，原生持有按目标路径命名的 Global mutex 防止活跃事务被另一会话当成崩溃恢复。
6. `ssPostInstall` 校验但不解除恢复；`ssDone` 最终成功事件才提交。Inno安装后脚本异常不是致命错误，因此错误另有锁存、后续载荷跳过、非零退出码和禁止启动/自删。取消/失败在引擎结束后执行补偿恢复。
7. 回滚先验证全部备份。后来修改的现存文件先无覆盖保存在 `conflicts/` 并校验后才恢复原件；无法证明由本次安装写入的新增文件保留原处并报冲突，不自动删除。恢复失败/中断保持日志及备份，修正冲突后重跑。
8. 备份和冲突不会自动清理，后续安装仅将旧完整备份改名保留；需用户自行确认后清理。只移除本次创建且仍为空的目录，从不递归删除安装目录。
9. 用户数据 `Documents/Dan Player` 及旧兼容数据路径不读取、不迁移、不改写。卸载程序属于Inno管理，不会删除清单外的音乐或歌单。

以上是每用户安装的边界，不把同权限恶意进程全面对抗作为安全沙箱承诺。资源耗尽、未知并发改写、磁盘故障等情况优先保留可恢复数据并报错。

## 成功后的两个动作

普通双击安装时，“打开播放器”与“删除本安装器并关闭”仅在用户明确点击后请求，最终提交成功后执行。更新模式使用播放器内已确认的重启请求，成功提交后自动重开播放器。关闭、取消、失败以及安装成功本身都不会删除安装器。

清理助手验证原始分发EXE的路径、进程句柄、文件ID、单链接属性、产品标识和SHA256，等待原安装进程退出后通过**同一已验证文件HANDLE**标记删除。超时或身份变化保留文件。没有shell删除命令、通配符、递归目录清理、计划任务或重启后删除。Inno自身负责它创建的临时目录；本助手不清理EXE所在父目录。

## 播放器发起的一键原位更新

普通双击安装仍显示目录和两个快捷方式选项。播放器发起更新时传入 `/DANUPDATE=1`、`/DIR=<当前程序目录>`、`/DANPARENTPID=<自身PID>`、`/DANUPDATEVERSION=<目标版本>` 及 `/DANUPDATEEVENT=Local\DanPlayer.Update.<64位随机十六进制>`；相关参数缺失、版本不匹配或静默更新请求不会退回到自动安装。

- Windows信任链、SHA256、同一叶签名证书及安装器产品/版本检查在**播放器的原生启动桥**执行。安装器不重复执行另一套WinVerifyTrust，也不安装证书；未受系统信任的自签名不会被当作已信任更新。普通手动安装和受验证更新是不同入口。
- 安装器只读核验既有清单、当前目录中的 `Dan Player.exe`、父进程映像路径及实际祖先链/创建时间。它持有准确的进程对象和拒写/删除的映像句柄，避免PID重用或等待时文件替换；不枚举并终止同名进程。
- 安装器核验后发出READY。启动桥仍接受本次请求时，才置位同名 `.Accepted` 事件并允许播放器正常退出。安装器等待Accepted与父进程成功退出；迟到或取消的握手不会被重新激活。父退出后释放映像文件句柄，进程对象保留到安装器结束。
- 等待使用250ms UI定时轮询，不阻塞窗口；父进程30秒未退出时可重试或取消。缺失Accepted的超时则终止这次交接，须从播放器重新发起。不会强杀、提权或自动关闭其他进程。
- 事务开始前再次核验固定目录、清单、主程序SHA256及受管理文件的占用状态；占用错误仍可取消/重试，尚不改写程序。更新跳过目录与快捷方式页，现有快捷方式文件原样保留，不新建用户未选择的快捷方式。
- 只有最终验证并提交成功才自动重开播放器；失败/取消沿用备份回滚，不启动损坏版本。此协议是同用户、无提权的安装流程，不将同权限恶意进程全面对抗描述为额外安全边界。

## 构建和测试

编译器必须由用户预先准备；脚本不会下载、运行外部安装器或改变全局环境。MSVC原生构建不依赖Flutter。

```powershell
# 严格编译与隔离原生测试；默认输出到仓库外 tool/qa-installer
.\scripts\verify_installer_native.ps1

# 仅用虚构载荷执行实际Inno流程，快捷方式重定向到同一沙盒
.\installer\tests\run_installer_sandbox.ps1

# 真实Inno更新流程：合成父播放器、私有非交互desktop、虚构载荷
.\installer\tests\run_installer_update_sandbox.ps1

# 两主题/四档字体基准的真实 Inno 离屏绘制；仅在沙盒安装虚构载荷
.\installer\tests\render_installer_ui.ps1

# 从主任务已经审计的便携目录生成本地安装器
.\scripts\build_windows_installer.ps1 -PayloadDirectory 'D:\path\to\audited-portable'
```

结果名为 `DanPlayer-<SemVer>-Setup-x64.exe`；`-QaBuild` 输出另带 `-QA`。所有构建输出进入唯一新目录，源字体、Logo和payload不被修改。原生DLL/cleanup可通过 `-NativeDirectory` 指定。显式签名流程应先签内嵌自有二进制、重新生成清单/安装器、再签外层EXE，并对最终字节生成校验；测试不会签名或导入证书。

原生测试覆盖路径、SemVer、旧便携校验、锁、备份故障、迟失败、崩溃恢复、硬链接、冲突保护、精确自删除、隐藏控件96/120/144/192DPI、明暗按钮文字/边角、原始透明 Logo 和真实字体选择。Inno QA 使用虚构字节而非播放器、四种快捷方式组合、Unicode最终路径、复制/晚期失败与实际卸载元数据；只在 `tool/qa-installer` 安装，不注册ARP、不启动真实音乐、不创建真实桌面快捷方式。普通用户取消单独在专用、从不切换到的 Windows desktop 上运行 QA 向导，满足 Inno 的可见窗口取消条件；短超时只限制自有测试job，退出后释放测试desktop。不读取现有桌面、不截图。

UI QA 只让自己创建的真实 Inno HWND 经 `WM_PRINT`/VCL `WM_PAINT` 绘制到内存，在专用 desktop 分别强制浅色/深色，不改变系统主题。虚构文件只安装在沙盒，经过真实目录页、安装流程和完成页，结束时只点普通“完成”，不点启动或自删。以像素检查按钮四角与实际父背景一致，并将正文 notebook 的遮挡区域加入绘制裁切检查，避免仅验证父矩形却漏掉兄弟控件遮盖。品牌图也检查边界、真实着色像素与透明四角。还检查路径行中心误差不超过1px、说明与磁盘提示不重叠、完成页动作居中及宽度上限、客户区边界及间距。

完整 Inno 页面在本机实际125% DPI下测试；另外以7/9/11/14pt四档字体基准调用 Inno 自身的缩放布局作为压力回归，不能把这些档位冒充操作系统换屏测试。独立原生按钮像素测试覆盖96/120/144/192 DPI对应尺寸。未改变 Windows 显示设置或强发 DPI 消息。所有输出只在仓库外 `tool/qa-installer`。不捕获屏幕，也不验证 DWM 非客户区合成，因此图中的标题栏外框不能代表真实 Windows 10/11 桌面效果。测试通过数量以具体运行日志为准，不以本文代替测试结果。
